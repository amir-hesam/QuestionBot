# ربات تلگرام سوالات تستی

ربات تلگرامی برای برگزاری آزمون‌های چهارگزینه‌ای روی هاست اشتراکی cPanel، بدون نیاز به SSH و بدون وابستگی خارجی. کل ربات با PHP خالص و MySQL نوشته شده و از طریق وب‌هوک (یا کران‌جاب در حالت poll) کار می‌کند.

## امکانات

- ساخت آزمون با عنوان، توضیح، زمان‌بندی، کد ورود اختیاری و فعال/غیرفعال کردن
- افزودن سوال چهارگزینه‌ای با تعیین پاسخ درست
- تصادفی‌سازی سوال‌ها و گزینه‌ها برای هر دانش‌آموز (قابل خاموش کردن)
- نمایش فوری پاسخ درست بعد از انتخاب (قابل خاموش کردن)
- شناسایی دانش‌آموز با «کد دانش‌آموزی» ساخته‌شده توسط ادمین
- قفل شدن کد دانش‌آموزی روی اولین اکانت تلگرام (با امکان آزادسازی توسط ادمین)
- فقط یک بار شرکت در هر آزمون برای هر دانش‌آموز
- تایمر سمت سرور با اعمال سخت‌گیرانه مهلت (پایان خودکار با کران‌جاب)
- ناوبری بین سوال‌ها با دکمه‌های ◀️ و ▶️ و ارسال نتیجه در پایان
- ارسال خودکار نتیجه هر دانش‌آموز به همه ادمین‌ها
- خروجی CSV از نتایج (سازگار با Excel)
- پنل ادمین داخل تلگرام
- پنل وب مدیریت با ورود امن؛ رمز عبور هر بار با دکمه «🔐 پنل وب» یا `/panel` در تلگرام ساخته می‌شود
- مدیریت دانش‌آموزان، آزمون‌ها، سوال‌ها، نتایج، پیام همگانی و ابزارهای نگهداری از پنل وب
- حالت‌های webhook و poll

## نیازمندی‌ها

- PHP 7.4 تا 8.3
- افزونه `pdo_mysql`
- افزونه `curl` (توصیه‌شده) — در صورت نبود، از `file_get_contents` استفاده می‌شود
- افزونه `mbstring` (اختیاری؛ جایگزین داخلی برای UTF-8 وجود دارد)
- MySQL یا MariaDB
- SSL معتبر روی دامنه (برای وب‌هوک الزامی است)
- یک ربات ساخته‌شده در [@BotFather](https://t.me/BotFather)

## ساختار فایل‌ها

```
telebot/
├── index.php          # دریافت وب‌هوک تلگرام
├── install.php        # نصب، ساخت جدول‌ها و ثبت وب‌هوک (با کلید)
├── poll.php           # دریافت آپدیت‌ها با کران‌جاب (حالت poll)
├── cron_finish.php    # پایان خودکار آزمون‌های زمان‌دار
├── export.php         # خروجی CSV نتایج
├── config.php         # تنظیمات (توکن، دیتابیس، ادمین‌ها، کلیدها، پنل)
├── schema.sql         # ساختار جدول‌ها
├── .htaccess          # مسدودسازی config.php و schema.sql
├── app/               # کلاس‌های ربات (دسترسی وب مسدود)
├── panel/             # پنل وب مدیریت (RTL)
│   ├── index.php      # ورود، مسیریابی و خروجی CSV
│   ├── pages/         # صفحه‌های پنل
│   ├── views/         # قالب ورود و چیدمان
│   └── assets/        # CSS و JS
└── tests/             # تست‌های smoke (دسترسی وب مسدود)
```

## نصب روی cPanel

### ۱) آپلود فایل‌ها

محتوای پوشه پروژه را در مسیری مثل `public_html/telebot` آپلود کنید. پوشه `app/` و فایل `config.php` نباید مستقیماً از مرورگر قابل اجرا باشند؛ فایل‌های `.htaccess` این کار را انجام می‌دهند.

### ۲) ساخت دیتابیس

در cPanel → MySQL Databases:

1. یک دیتابیس بسازید (مثلاً `user_telebot`).
2. یک کاربر بسازید و به دیتابیس با دسترسی کامل وصل کنید.
3. نام دیتابیس، نام کاربر و رمز را یادداشت کنید.

### ۳) تنظیم `config.php`

```php
'token'      => 'TOKEN_FROM_BOTFATHER',
'db'         => array(
    'host' => 'localhost',
    'name' => 'user_telebot',
    'user' => 'user_telebot',
    'pass' => 'DB_PASSWORD',
),
'admin_ids'  => array(123456789),
'secret_token' => 'یک-رشته-تصادفی-طولانی',
'admin_key'    => 'یک-کلید-تصادفی-دیگر',
'mode'       => 'webhook',
'webhook_url' => '',
'timezone'   => 'Asia/Tehran',
'code_length' => 6,
'panel'      => array(
    'user' => 'admin',
    'url' => '',
    'idle_timeout' => 1800,
    'pass_ttl' => 0,
    'password_length' => 16,
),
```

- `admin_ids`: شناسه عددی ادمین‌ها را از [@userinfobot](https://t.me/userinfobot) بگیرید. چند ادمین مجاز است.
- `secret_token`: فقط حروف انگلیسی، عدد، `_` و `-`؛ در ثبت وب‌هوک استفاده می‌شود.
- `admin_key`: کلید دسترسی به `install.php`، `cron_finish.php`، `poll.php` و `export.php`.
- `webhook_url`: خالی بگذارید تا خودکار از آدرس فعلی ساخته شود.
- `panel.user`: نام کاربری ورود به پنل وب.
- `panel.url`: آدرس کامل پوشه پنل (مثل `https://example.com/telebot/panel/`). اگر خالی باشد از `webhook_url` یا آدرس فعلی حدس زده می‌شود. در حالت `poll` این مقدار را تنظیم کنید.
- `panel.idle_timeout`: مدت بی‌کاری نشست وب به ثانیه (پیش‌فرض ۳۰ دقیقه).
- `panel.pass_ttl`: عمر رمز پنل به ثانیه؛ `0` یعنی بدون انقضا (تا چرخش بعدی).
- `panel.password_length`: طول رمز تصادفی پنل.

> این دو کلید را حتماً از مقدارهای پیش‌فرض تغییر دهید.

### ۴) اجرای نصب

آدرس زیر را باز کنید:

```
https://example.com/telebot/install.php?key=ADMIN_KEY
```

سپس:

1. **ساخت جدول‌ها** را بزنید.
2. **ثبت وب‌هوک** را بزنید (دکمه «تست توکن» و «وضعیت وب‌هوک» برای بررسی است).
3. مطمئن شوید همه موارد وضعیت سبز هستند.

اگر هاست شما از وب‌هوک پشتیبانی نمی‌کند، به جای ثبت وب‌هوک، «حذف وب‌هوک» را بزنید، `mode` را در `config.php` روی `poll` بگذارید و کران‌جاب `poll.php` را تنظیم کنید.

### ۵) کران‌جاب پایان خودکار

در cPanel → Cron Jobs یک کران‌جاب هر دقیقه بسازید:

```
wget -q -O /dev/null "https://example.com/telebot/cron_finish.php?key=ADMIN_KEY"
```

یا:

```
curl -s "https://example.com/telebot/cron_finish.php?key=ADMIN_KEY" > /dev/null
```

در حالت `poll` این را هم هر دقیقه اجرا کنید:

```
wget -q -O /dev/null "https://example.com/telebot/poll.php?key=ADMIN_KEY"
```

### ۶) شروع استفاده

در تلگرام به ربات `/start` بفرستید. اگر شناسه‌تان در `admin_ids` باشد، پنل مدیریت باز می‌شود.

برای ورود به پنل وب، در چت خصوصی ربات دکمه «🔐 پنل وب» را بزنید یا `/panel` بفرستید. ربات یک رمز یک‌بارمصرف می‌فرستد؛ با نام کاربری `panel.user` و آن رمز وارد شوید.

پس از اطمینان از نصب، فایل `install.php` را حذف کنید.

## دستورات ادمین

| دستور | کار |
| --- | --- |
| `/start` | پنل مدیریت |
| `/panel` | ساخت رمز جدید پنل وب و باطل‌کردن نشست‌های قبلی |
| `/addstudent` | ثبت دانش‌آموز و ساخت کد (نام، نام خانوادگی، کلاس، کد دلخواه) |
| `/student <کد>` | مشاهده مشخصات و آزمون‌های یک دانش‌آموز |
| `/find <متن>` | جستجو بر اساس نام، کد یا کلاس |
| `/students [صفحه]` | لیست دانش‌آموزان |
| `/unlock <کد>` | آزادسازی قفل کد از اکانت تلگرام |
| `/resetattempt <کد> <آزمون>` | حذف تلاش قبلی برای شرکت مجدد |
| `/delstudent <کد>` | حذف دانش‌آموز و نتایجش |
| `/newquiz` | ساخت آزمون جدید |
| `/addq <آزمون>` | افزودن سوال به آزمون |
| `/questions <آزمون>` | نمایش سوال‌ها |
| `/editquiz <آزمون>` | تنظیمات آزمون (زمان، کد ورود، تصادفی‌سازی، نمایش پاسخ، فعال/غیرفعال) |
| `/quizzes` | لیست آزمون‌ها |
| `/delq <سوال>` | حذف سوال |
| `/delquiz <آزمون>` | حذف آزمون و همه داده‌هایش |
| `/toggle <آزمون>` | فعال/غیرفعال کردن آزمون |
| `/stats <آزمون>` | آمار شرکت‌کنندگان، میانگین و بهترین نمره |
| `/results <آزمون>` | ۱۵ نتیجه اخیر |
| `/broadcast <متن>` | ارسال پیام به همه کاربران ربات |
| `/cancel` | لغو عملیات جاری |

در ویزاردها می‌توانید به جای وارد کردن مقدار، `/skip` بفرستید (برای فیلدهای اختیاری) و با `/cancel` عملیات را لغو کنید.

## جریان دانش‌آموز

1. `/start` و انتخاب آزمون.
2. وارد کردن کد ورود آزمون (اگر برای آزمون تعیین شده باشد).
3. وارد کردن کد دانش‌آموزی.
4. کد در اولین ورود به اکانت تلگرام قفل می‌شود.
5. نمایش سوال‌ها با دکمه‌های گزینه و ناوبری؛ هر پاسخ بلافاصله ذخیره می‌شود.
6. انتخاب «پایان آزمون» و تأیید.
7. نمایش نمره، درصد و (در صورت فعال بودن) بررسی سوالات غلط.

اگر زمان آزمون تمام شود، پاسخ‌های بعدی پذیرفته نمی‌شوند و نتیجه با وضعیت «اتمام زمان» ثبت و به ادمین‌ها ارسال می‌شود.

## پنل وب مدیریت

آدرس پیش‌فرض: `https://example.com/telebot/panel/`

- **فعال‌سازی:** در چت خصوصی ربات دکمه «🔐 پنل وب» یا دستور `/panel` را بزنید. هر بار یک رمز تصادفی جدید ساخته می‌شود و رمز و نشست‌های وب قبلی باطل می‌شوند.
- **نام کاربری:** مقدار `panel.user` در `config.php` (پیش‌فرض `admin`).
- **امکانات:** داشبورد آمار، مدیریت و ویرایش دانش‌آموزان، آزادسازی قفل تلگرام، ریست/پایان دستی تلاش‌ها، ساخت و ویرایش آزمون و سوال، جابه‌جایی ترتیب سوال‌ها، مشاهده جزئیات پاسخ‌ها، جستجو و خروجی CSV نتایج، پیام همگانی و ابزارهای نگهداری.
- **امنیت:** نشست ۳۰ دقیقه‌ای، توکن CSRF، کوکی HttpOnly/SameSite، محدودیت ۵ تلاش ناموفق ورود در ۱۵ دقیقه، خروج خودکار با تغییر رمز، هدرهای امنیتی و CSP.
- اگر پوشه پنل را جابه‌جا کردید یا از حالت `poll` استفاده می‌کنید، `panel.url` را در `config.php` تنظیم کنید.

## خروجی CSV

```
https://example.com/telebot/export.php?key=ADMIN_KEY
https://example.com/telebot/export.php?key=ADMIN_KEY&quiz=3
https://example.com/telebot/export.php?key=ADMIN_KEY&quiz=3&q=نام
```

فایل با UTF-8 BOM ساخته می‌شود تا در Excel درست نمایش داده شود. ستون‌ها: ردیف، کد دانش‌آموزی، نام، نام خانوادگی، کلاس، آزمون، شناسه آزمون، نمره، از، درصد، زمان شروع، زمان پایان، مدت (ثانیه)، نحوه پایان. پارامتر `q` روی کد، نام، نام خانوادگی، کلاس و عنوان آزمون جستجو می‌کند.

## امنیت

- `config.php`، `schema.sql` و پوشه‌های `app/` و `tests/` با `.htaccess` مسدود شده‌اند.
- درخواست وب‌هوک با هدر `X-Telegram-Bot-Api-Secret-Token` بررسی می‌شود.
- آپدیت‌های تکراری با جدول `processed_updates` حذف می‌شوند.
- همه کوئری‌ها Prepared Statement هستند.
- خروجی‌ها قبل از ارسال HTML-escape می‌شوند.
- تلاش برای کد ورود آزمون محدود شده است (۵ بار در ۱۰ دقیقه).
- در CSV از فرمول‌های مخرب Excel جلوگیری می‌شود.
- رمز پنل وب فقط با درخواست ادمین از چت خصوصی ربات ساخته می‌شود؛ هش رمز در جدول `kv` ذخیره و با هر چرخش، نشست‌های وب باطل می‌شوند.
- پنل وب از CSRF، کوکی‌های HttpOnly/SameSite (و Secure روی HTTPS)، محدودیت ورود و هدرهای امنیتی استفاده می‌کند. پوشه `panel/pages/` مستقیماً قابل دسترسی نیست.
- پس از نصب، `install.php` را حذف کنید و `admin_key` و `secret_token` را تغییر دهید.

## تست

بدون نیاز به دیتابیس و شبکه:

```
php tests/smoke.php
```

بررسی سینتکس همه فایل‌ها:

```
php -l index.php
php -l app/StudentFlow.php
```

## عیب‌یابی

- **ربات جواب نمی‌دهد:** «وضعیت وب‌هوک» را در `install.php` ببینید. آدرس باید `https` باشد و SSL معتبر داشته باشد.
- **خطای دیتابیس:** اطلاعات `config.php` را بررسی و دکمه «ساخت جدول‌ها» را دوباره بزنید.
- **پیام «دسترسی ندارید»:** شناسه عددی شما در `admin_ids` نیست.
- **کد دانش‌آموز قفل شده:** با `/unlock <کد>` آزاد کنید.
- **دانش‌آموز قبلاً شرکت کرده:** با `/resetattempt <کد> <آزمون>` تلاش قبلی را حذف کنید.
- **آزمون زمان‌دار تمام نمی‌شود:** کران‌جاب `cron_finish.php` را بررسی کنید.
- **حالت poll کار نمی‌کند:** اول وب‌هوک را حذف کنید؛ Telegram هم‌زمان اجازه getUpdates نمی‌دهد.
- **پنل وب باز نمی‌شود:** ابتدا در چت خصوصی ربات `/panel` بزنید. آدرس و تنظیم `panel.url` را بررسی کنید و مطمئن شوید کوکی‌ها مسدود نیستند.
- **رمز پنل را گم کرده‌اید:** دوباره `/panel` یا دکمه «🔐 پنل وب» را بزنید؛ رمز جدید ساخته و رمز قبلی باطل می‌شود.
- **ورود پنل قفل شده:** ۱۵ دقیقه صبر کنید یا از صفحه «ابزارها» سوابق قفل ورود را پاک کنید.
- **فارسی به‌هم‌ریخته است:** مطمئن شوید دیتابیس و جدول‌ها `utf8mb4` هستند.

## جدول‌های دیتابیس

| جدول | کاربرد |
| --- | --- |
| `bot_users` | کاربران ربات (برای broadcast) |
| `student_codes` | کدها، نام، کلاس و قفل اکانت |
| `quizzes` | آزمون‌ها و تنظیماتشان |
| `questions` | سوال‌ها و گزینه‌ها |
| `attempts` | تلاش‌های دانش‌آموزان و ترتیب تصادفی |
| `answers` | پاسخ‌های ذخیره‌شده |
| `bot_sessions` | وضعیت ویزاردها |
| `kv` | مقادیر ساده (offset در poll، رمز پنل وب و محدودیت ورود) |
| `processed_updates` | جلوگیری از پردازش تکراری آپدیت‌ها |

## نکته‌ها

- پاسخ‌ها همیشه با حرف اصلی گزینه (`A` تا `D`) ذخیره می‌شوند؛ بنابراین تصادفی‌سازی گزینه‌ها نتیجه را خراب نمی‌کند.
- برای هر دانش‌آموز در هر آزمون فقط یک رکورد `attempt` ساخته می‌شود؛ برای شرکت مجدد باید ادمین تلاش قبلی را حذف کند.
- زمان‌ها با منطقه زمانی `Asia/Tehran` و ساعت سرور محاسبه می‌شوند؛ ساعت هاست را درست تنظیم کنید.
- اگر تعداد سوال‌ها زیاد است، پیام نتیجه به چند بخش تقسیم می‌شود.
